# Neosis GitHub Wiki Package

This folder contains GitHub Wiki-ready Markdown files generated from the uploaded Neosis repository.

Recommended upload method:

1. Enable Wiki in your GitHub repository settings.
2. Clone the wiki repo: `git clone https://github.com/<username>/<repo>.wiki.git`
3. Copy all `.md` files from this folder into the wiki repo.
4. Commit and push.

Start with `How-to-Upload-This-Wiki.md` if you need exact commands.
